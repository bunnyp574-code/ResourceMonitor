# 💻 ResourceMonitor

เป็นโปรแกรมสำหรับเคลียร์แรม (RAM) และล้างไฟล์ขยะ (Temporary Files) บนระบบปฏิบัติการ Windows 10 และ Windows 11 เพื่อช่วยเพิ่มความเร็วและคืนพื้นที่ให้กับคอมพิวเตอร์ของคุณ

## ✨ คุณสมบัติของโปรแกรม (Features)
- 🚀 เคลียร์หน่วยความจำ RAM ที่ไม่ได้ใช้งานให้กลับมาว่างอีกครั้ง
- 🧹 ล้างไฟล์ขยะในโฟลเดอร์ Temp ของระบบอย่างปลอดภัย
- 🛠️ รองรับการทำงานทั้งบน Windows 10 และ Windows 11

## 📦 วิธีดาวน์โหลดและใช้งาน (How to run)
1. ดาวน์โหลดไฟล์ `ResourceMonitor.exe` จากโปรเจกต์นี้
2. ดับเบิ้ลคลิกที่ไฟล์เพื่อเปิดใช้งานโปรแกรมได้ทันที (ไม่จำเป็นต้องติดตั้ง)
